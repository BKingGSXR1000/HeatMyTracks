# HeatMyTracks
Privacy-first local GPS heatmap viewer for GPX, GPX.GZ, FIT and FIT.GZ files.

Third-party libraries and map tile providers have their own licenses and terms:

- Leaflet
- Leaflet.heat
- fit-file-parser
- OpenStreetMap / CARTO / Esri map tiles

GPS files are processed locally in the browser and are not uploaded by this app.
